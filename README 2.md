Այս լաբորատոր աշխատանքում ուսումնասիրվել և գործնականում կիրառվել են ծրագրային ապահովման պաշտպանության (Code Obfuscation) երկու հիմնական ալգորիթմներ։

1. Տվյալների խեղաթյուրում (String Encoding / XOR Obfuscation)
Կոդում առկա զգայուն տվյալները (տողերը) թաքցնելու նպատակով կիրառվել է XOR գործողությունը։ Ինչպես երևում է կից ներկայացված սքրինշոթերում, տեքստը պահպանվում է կոդավորված թվերի կամ սիմվոլների զանգվածի տեսքով, ինչը անհնար է դարձնում դրա ուղիղ ընթերցումը ստատիկ վերլուծության ժամանակ (օրինակ՝ strings հրամանով)։ Ծրագրի աշխատանքի ընթացքում (runtime) տվյալները ապակոդավորվում են հատուկ բանալիով (key)։

2. Կատարման հոսքի բարդացում (Control Flow Obfuscation և Dead Code)
Ծրագրի տրամաբանությունը քողարկելու համար կոդում ինտեգրվել է State Machine և արհեստական ցիկլեր, ինչպես նաև ավելացվել է «մեռած կոդ» (Dead Code), որը երբեք չի կատարվում, սակայն շեղում է հակադարձ ինժեներիայի (reverse engineering) գործիքների աշխատանքը։ Ծրագիրը պահպանում է իր ֆունկցիոնալությունը, սակայն դրա կառուցվածքային վերլուծությունը զգալիորեն բարդանում է:
