Այս լաբորատոր աշխատանքի շրջանակներում ուսումնասիրվել են ցանցային էկրանների (Firewall) աշխատանքի հիմնական սկզբունքները և պորտերի դերը ցանցային անվտանգության մեջ։

1. Ծրագրային մոդելավորում (Python)
Կիրառվել է Python լեզվով գրված սքրիպտ (firewall-1.py), որը psutil գրադարանի միջոցով սկանավորում է համակարգի ակտիվ ցանցային կապերը և նույնականացնում է պրոտոկոլները։ Ծրագրում մոդելավորվել է Firewall-ի տրամաբանությունը՝ ստեղծվել են վիրտուալ կանոններ մուտքային (inbound - պորտ 80) և ելքային (outbound - պորտ 22) տրաֆիկի արգելափակման համար։ Տրաֆիկի 5 վայրկյան տևողությամբ մոնիտորինգի արդյունքում առանձնացվել են առավել ծանրաբեռնված պորտերը, և ստացված ամբողջ վիճակագրությունը (ներառյալ կիրառված կանոնները) պահպանվել է JSON ֆայլում։

2. Իրական կանոնների կիրառում (OS մակարդակ)
Մոդելավորումից բացի, իրականացվել է պորտի ֆիզիկական արգելափակում օպերացիոն համակարգի մակարդակում։ Windows-ի PowerShell հրամանային տողի միջոցով ստեղծվել է նոր անվտանգության կանոն (New-NetFirewallRule), որն արգելափակում է Inbound TCP տրաֆիկը 80 պորտի վրա։ Այսպիսով, գործնականում հաստատվել է OS մակարդակում տրաֆիկի ֆիլտրման ֆունկցիոնալությունը։
