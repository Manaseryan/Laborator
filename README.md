Այս լաբորատոր աշխատանքում ուսումնասիրվել և գործնականում իրականացվել են ծրագրային ապահովման պաշտպանության (Software Protection) և հակադարձ ինժեներիայի (Reverse Engineering) հիմնական կոնցեպտները։

1. Պարզագույն բինար փաթեթավորող (Simple Executable Packer)
Ստեղծվել է գործարկվող ֆայլերի փաթեթավորող (packer), որը բաղկացած է երկու մոդուլից՝ Builder և Stub։ Builder-ը կարդում է թիրախային ծրագրի (program.exe) բինար կոդը, կոդավորում է այն բայթ առ բայթ՝ օգտագործելով XOR ալգորիթմ (0xAA բանալիով), և պահպանում որպես .bin ֆայլ: Գործարկման ժամանակ (runtime) Stub ծրագիրը կարդում է կոդավորված ֆայլը, ապակոդավորում է այն օպերատիվ հիշողության մեջ, վերականգնում է բնօրինակ գործարկվող ֆայլը և ավտոմատ կերպով աշխատեցնում այն։

2. Գաղտնաբառի ստուգման ծրագիր (Crackme) և Anti-debugging
Մշակվել է Crackme ծրագիր, որի նպատակն է ստուգել օգտատիրոջ մուտքագրած գաղտնաբառը։ Անվտանգությունն ապահովելու նպատակով ճիշտ գաղտնաբառը ծրագրի կոդում պահպանված չէ բաց տեքստով (plain text), այլ ներկայացված է որպես XOR-ով (0x55 բանալիով) կոդավորված զանգված: Ծրագրում ներդրվել է նաև դեբագինգի դեմ պաշտպանության (anti-debugging) մեխանիզմ՝ կիրառելով Windows API-ի IsDebuggerPresent() ֆունկցիան, որը հայտնաբերում է կոդի դինամիկ վերլուծության փորձերը և անմիջապես ընդհատում ծրագրի աշխատանքը։
