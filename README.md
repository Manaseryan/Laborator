Այս լաբորատոր աշխատանքի շրջանակներում կատարվել է բինար ֆայլի (ELF/PE ձևաչափերի) ուսումնասիրություն և ռևերս-ինժեներինգի (reverse engineering) հիմնական մեթոդների պրակտիկ կիրառում։

Կատարված քայլերը՝

Ծրագրի նախապատրաստում: C++ լեզվով գրվել և կոմպիլացվել է ծրագիր, որը պարունակում է տեքստային արժեք և պայմանական ճյուղավորում (if-else)։

Տվյալների փոփոխում (String Patching): HEX խմբագրիչի միջոցով բինար ֆայլի .rodata (կամ .rdata) սեկցիայում գտնվել է սկզբնական հաստատունը ("Hello, World!") և փոխարինվել նոր արժեքով ("Hacked World!")։ Խստորեն պահպանվել է բայթերի սկզբնական երկարությունը՝ ֆայլի կառուցվածքը չվնասելու նպատակով։

Տրամաբանության փոփոխում (Logic Patching): Կիրառվել է objdump գործիքը՝ ծրագրի ասեմբլերային կոդը վերլուծելու և համեմատության (cmp) հրահանգին հաջորդող պայմանական անցման (jne) ճշգրիտ հասցեն (memory offset) գտնելու նպատակով։ Այնուհետև HEX խմբագրիչով այդ հասցեում գտնվող հրահանգի բայթը փոխարինվել է հակառակ տրամաբանությամբ (jne -> je, 75 HEX արժեքը դարձել է 74)։

Արդյունք: Ծրագրի աշխատանքի տրամաբանությունը հաջողությամբ շրջվել է, և գործարկման ժամանակ ծրագիրն ընտրել է այլ ճյուղ՝ առանց սկզբնական կոդը (source code) փոփոխելու և վերակոմպիլացնելու։
